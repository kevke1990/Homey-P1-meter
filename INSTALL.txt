CHARGEE SPARKY v1.3.4

CRITICAL WIDGET LOADING FIX

The widget now uses the official onHomeyReady(Homey) initialization
pattern. Homey.ready() is called immediately inside that callback.

This prevents Homey's native loading spinner from remaining visible when
the Homey API object is not ready at page-script evaluation time.

Also retained:
- Chargee Sparky device selector (driver p1_dongle)
- 5-second live refresh
- cached widget API device
- P1 capability-write throttling
- Homey Insights / Energy cumulative meter configuration
- no custom history database

Validate:
  homey app validate --level publish

Run:
  homey app run

IMPORTANT:
Remove the old Energy Dashboard widget instance and add a NEW widget
instance after installing v1.3.4. This ensures the new widget HTML is
loaded rather than a cached old instance.
