CHARGEE SPARKY v1.4.1

FIXED: p1_grid_import_power 404

Root cause in v1.4.0:
The TCP connection was started before addCapability() had completed.
The P1 stream could therefore deliver a telegram while the new custom
Insight capabilities were still being added. setCapabilityValue() then
returned HTTP 404 "Invalid Capability".

v1.4.1:
- waits for Insight capability migration before opening TCP
- adds each missing capability sequentially
- confirms a capability exists before every Insight write
- safely skips a capability if Homey could not add it
- custom Insight capabilities explicitly use uiComponent=sensor
- Insights remain enabled
- Homey Energy configuration remains unchanged
- v1.3.4 fast widget architecture remains unchanged

IMPORTANT:
Because these are new capabilities, after updating the app:
1. Stop the old app runner.
2. Start v1.4.1.
3. Open the existing Chargee Sparky device.
4. Wait 5-10 seconds for capability migration.
5. If the device still does not show the Insights entry, delete and pair
   the P1 device once more. New driver capabilities are not automatically
   added to existing devices; the migration code handles this, but re-pairing
   is the clean fallback.

Validate:
  homey app validate --level publish

Run:
  homey app run
