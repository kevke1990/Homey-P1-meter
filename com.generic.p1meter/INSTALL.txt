CHARGEE SPARKY v1.4.3

Insights are now backed by five properly declared custom number capabilities
with insights=true. They are migrated to existing devices with addCapability()
and populated from the P1 telegram. The standard Homey Energy capabilities
remain unchanged.

After starting, the log should show:
  Insights capability toevoegen: ...
  Insights capability toegevoegd: ...
  Eerste geldige DSMR-telegram ontvangen: ...

Then long-press Chargee Sparky. Homey should expose the Insights shortcut
for the measuring device. Homey Web can also be used to inspect Insights.
