# Chargee Sparky Professional Dashboard

Package built for Homey CLI 4.0.5 / Node 20.

Install:
1. Extract this directory.
2. Run `homey app validate`.
3. Run `homey app run`.

The widget is registered as `energy_dashboard` and is intended for Homey Pro/local.

Important: historical charts require Homey Insights history. The dashboard shows live device values immediately. This package does not fabricate historical measurements.
