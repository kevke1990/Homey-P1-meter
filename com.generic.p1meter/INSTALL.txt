CHARGEE SPARKY v1.2.2

FIX:
The Energy Dashboard previously failed with:
  Cannot read properties of undefined (reading 'getDevice')

Cause:
The widget API used `homey.devices.getDevice()`, but the Homey Apps SDK
does not expose `homey.devices` in this context.

Fix:
The widget API now resolves the selected P1 device through:
  homey.drivers.getDriver('p1_dongle')
  -> driver.getDevices()
  -> device.getId()

Live capabilities are read with device.getCapabilityValue().

Also improved:
- first chart bucket uses the last sample before the selected period
- no fake historical values
- existing P1 history remains compatible

Run:
  homey app validate
  homey app run
