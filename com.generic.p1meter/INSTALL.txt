CHARGEE SPARKY v1.4.0

HOMEY INSIGHTS EDITION

The screenshot showed that the P1 device did not expose the Insights entry
point. v1.4.0 makes Insights explicit rather than relying only on Homey's
automatic Insights generation for system capabilities.

Added five read-only, device-level Insight capabilities:
- p1_grid_import_power      Netafname (W)
- p1_grid_export_power      Teruglevering (W)
- p1_imported_energy        Afgenomen energie (kWh)
- p1_exported_energy        Teruggeleverde energie (kWh)
- p1_gas_meter              Gasmeterstand (m³)

Each custom capability has "insights": true and is synchronized from the
existing P1 system capabilities. The original system capabilities remain
intact for Homey Energy, including cumulative import/export configuration.

IMPORTANT:
Existing Homey devices do not automatically receive newly declared
capabilities. v1.4.0 attempts to migrate them using addCapability(), but
for the cleanest Homey UI/Insights result remove the old Chargee Sparky
device and pair it again after installing v1.4.0.

Then:
  homey app validate --level publish
  homey app run

After re-pairing:
Devices -> long press Chargee Sparky P1 Meter -> Insights

You should see the five Chargee Sparky metrics as device-level Insights.
