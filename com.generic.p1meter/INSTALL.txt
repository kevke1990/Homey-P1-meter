CHARGEE SPARKY v1.3.0

ARCHITECTURE CHANGE
- Removed the custom 31-day history database from the device.
- Homey Insights is now the primary historical source.
- The P1 driver is configured as a cumulative Homey Energy meter.
- Imported energy: meter_power
- Exported energy: meter_power.returned
- Gas: meter_gas
- Existing paired devices receive the energy configuration through setEnergy()
  during startup, so re-pairing should not be necessary.

WIDGET
- Live-only cockpit for very fast loading.
- No getStoreValue(history), sorting or chart aggregation.
- Refreshes every 15 seconds.
- Historical graphs/energy reports are handled by Homey Insights / Energy.

INSTALL
  homey app validate
  homey app run

After running, open the existing Energy Dashboard widget and select the
Chargee Sparky P1 Meter if the device selector asks for it.
